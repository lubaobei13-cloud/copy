Copy · 本地剪贴板历史

打开 D:\copy\Copy.exe 即可使用，不需要安装。支持 Windows 10 / 11 x64。

日常操作
1. 程序运行后，复制文字、截图/图片、文件或文件夹，会自动记录。
2. Ctrl + Alt + V 打开或收起小窗，也可以点击系统托盘中的灰绿色剪贴板图标。
3. 输入关键词搜索，或按文字 / 图片 / 文件 / 置顶筛选。
4. 点击卡片内容，将它重新复制；回到目标窗口按 Ctrl + V 粘贴。
5. “展开”查看全文或大图；“置顶”保留常用内容；“删除”删除单条历史。
6. 右上角 × 和 Esc 只收起小窗，不会退出。托盘菜单或设置菜单可彻底退出。
7. “暂停”期间不记录；点“继续”恢复，只记录之后新复制的内容。
8. 设置中可以打开“开机启动”，默认关闭；也可以开启窗口始终置顶。
9. 默认窗口为 380 × 340，可以拖动标题栏移动窗口，拖动边缘调整大小。Ctrl + F 定位搜索框。
10. 滚轮每格移动约 42 像素，可以逐步查看较高的图片记录。保留多行预览和展开功能。

保存规则
- 数据只保存在程序旁边的 data 文件夹，不连接网络、不上传。
- 普通记录最多 1000 条，超出后自动删除最旧的普通记录；置顶记录保留。
- 内容总容量 200 MB，包含文字、图片和缩略图。数据库文件另有少量索引开销。
- 单张图片最多 20 MB / 4000 万像素，单条文字最多 200 万字符。
- 连续相同内容只保存一次；点击历史重新复制不会生成重复记录。
- 重启后历史仍保留；完全退出程序期间不能记录。无法补回运行前的历史。
- 应用通过标准格式明确禁止记录的剪贴板内容不会保存。

支持范围
- 文字按纯文本保存，不保留网页/Office 的富文本排版。
- 图片支持标准 Windows 位图及 PNG 剪贴板格式，不提供图片文字识别。
- 单张本地图片文件（包括微信提供的 PNG 文件路径）会读取为图片，保存像素和缩略图，点击后复制图片。
- 普通文件、文件夹及多文件选择只保存路径，不备份本体。原文件移动或删除后无法通过历史恢复。
- 恢复文件历史时按“复制”处理，不会自动移动或删除文件。
- 专有应用对象（例如 CAD 对象）若没有文字、图片、文件表示，则不能记录。
- 极快连续复制、源应用禁止读取或长时间占用剪贴板时，可能漏过内容。

隐私与清理
- 普通剪贴板内容可能包含敏感信息，请按需暂停、删除或清空。
- 设置 -> 清空普通记录 会保留置顶；清空全部记录 会同时删除置顶。
- 清空历史不会修改当前系统剪贴板。
- 自动错误日志仅包含异常类型和代码调用位置，不记录复制内容。

文件位置
Copy.exe              可直接双击运行的程序
src\                  完整 C# / XAML 源码
build.ps1             使用系统自带 .NET Framework 编译器重新构建
data\history.db       本地 SQLite 历史数据库
data\settings.xml     窗口大小、位置和置顶设置
tests\latest-results.txt  最近一次自动测试结果

卸载
先在设置中关闭“开机启动”，再从托盘选择退出 Copy，之后删除整个 copy 文件夹和快捷方式。

开发
powershell -NoProfile -ExecutionPolicy Bypass -File D:\copy\build.ps1
Copy.exe --self-test   运行隔离数据库与系统剪贴板集成测试（先退出正在运行的正式版，避免其他实例记录测试剪贴板）
Copy.exe --test-mode   打开使用 tests\ui-data 数据的测试窗口
Copy.exe --background  收起到托盘启动

Quicker 截图与记录时机
Copy 只在系统剪贴板变化后读取内容，不会主动截图。
Quicker 快速截图若开启“复制到剪贴板”，框选结束就会写入图片，Copy 会随之记录。
若希望只在手动点击复制后记录，需要关闭 Quicker 对应截图方式的自动复制选项。
若“快速截图”本身未启用，应核对鼠标键实际触发的动作或其他截图软件，不能仅凭图片来源准确判断是否手动复制。
官方说明：https://getquicker.net/KC/Manual/Doc/quick-shot
